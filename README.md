# Cinematic Soul Sessions

You mean soulful, kinda cinematic hip-hop energy. Add to the prompt. Use deep blacks, charcoal greys, soft off-white, subtle grain textures, editorial photography, and huge typography. Not neon purple AI stuff. Navigation is minimal. Big artwork breathes on the drop pages. Buttons look like clean labels, not giant pills. The vibe is cinematic,Start with one page, an access code leading to a welcome animation, then the exclusive content. Add a merch tab that simply says "coming soon." Colors stay dark and cinematic. Textures use subtle film grain, not glitch spam. Typography is bold and clean. For the exclusive page, use big artwork, "listen now" and "download" buttons, and smooth page transitions. Mobile first, feels like getting a private invite to something special, not a Lovable template.
